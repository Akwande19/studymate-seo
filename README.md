# StudyMate SEO Website

StudyMate is a Next.js website for a student productivity app, study planner, academic task manager, and deadline tracker.

The site includes SEO-focused product pages, pricing, contact, structured data, robots metadata, a sitemap, and long-form blog articles for student planning topics.

## Tech Stack

- Next.js App Router
- React
- TypeScript
- Tailwind CSS

## Local Development

```bash
npm install
npm run dev
```

## Production Build

```bash
npm run build
```
